# Blogauto web design

The canonical interface is a focused Korean writing workspace. Its primary path is topic input → draft generation → review → explicit publish. Keep publishing distinct from generation because publishing changes the user's Naver blog.

Use a warm ivory canvas, dark ink text, a restrained evergreen accent, and subtle borders. The top bar shows the product name and cloud status. The main column contains the editor and draft. A narrower right column contains login status, budget note, and recent jobs. Mobile collapses to one column. Use clear type and button labels; do not imply an account is connected or a post is published until the server confirms it.

Never show secret keys in the browser. Naver credentials are entered only in the remote Naver browser view. Surface configuration errors as actionable text without exposing server secrets.
