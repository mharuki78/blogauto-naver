  1. 앱에 블로그를 추가하고 확장 연결 코드을 누르세요.
  2. 표시된 연결 코드를 아래에 입력하세요.
  3. 로그인이 필요할 때만 열린 블로그 화면에서 직접 로그인하세요.

연결 확인 중…

계정별로 로그인 유지

앱에서 해당 계정의 ‘Chrome 열기’를 눌러 연 창에 연결하세요. Google 계정은 필요하지 않습니다. 네이버는 계정별 창을 사용합니다. 티스토리는 공용 창 한 개를 연결하면 지정된 여러 블로그에 같은 로그인을 사용합니다. 앱이나 확장은 로그인 쿠키를 읽거나 교체하지 않습니다.

작성 중에는 대상 탭을 조작하지 마세요. 확장의 페이지 스크립트가 입력합니다. 브라우저 자동화 드라이버나 디버거를 사용하지 않습니다.
